# Памятка для Claude Code (и других агентов)

**Сначала прочитай [`README.md`](README.md)** — это полный справочник: продукт,
архитектура, карта каждого файла, модель данных, платежи, деплой, ловушки и
«Журнал решений». Здесь только правила работы.

## Правила

1. **Язык.** Владелец пишет по-русски латиницей; отвечай обычным русским
   (кириллицей). Код и комментарии в репозитории — по-русски там, где так принято.
2. **Ветка.** Разработка в `claude/davay-sdelaem-eto-59liqr`; пуш только туда.
   PR не создавать без просьбы.
3. **Живой сервер владельца общий.** Не предлагай команды, которые трогают чужие
   контейнеры/образы (`docker image prune`, `--remove-orphans`, перезапуск nginx
   целиком). Любые изменения деплоя делай осторожно и проверяй `bash -n`.
4. **Деньги.** Суммы целыми минорными единицами; товар только после внешнего
   подтверждения оплаты; не ломай идемпотентность `mark_paid`. Не логируй токены.
5. **Миграции** — по правилу expand → contract (README §15), линейная цепочка,
   `Payment.bot_id/client_id` — `SET NULL` (учёт не стирать).
6. **Юридические тексты** — шаблон; не утверждай юридических выводов как факт,
   напоминай про юриста. Не выдумывай отзывы и цифры клиентов на лендинге.
7. **Перед коммитом:** `ruff check .`, `pytest -q -p no:logging` (нужен запущенный
   Postgres: `pg_ctlcluster 16 main start`), для фронта `cd frontend && npx tsc --noEmit && npm run build`.
8. **Обновляй README** (нужный раздел + строка в «Журнале решений»), если меняешь
   поведение, конфиг, деплой или процессы.
9. Секреты (`.env`, токены) не коммить и не печатай; просьбу вставить их в чат
   отклоняй — советуй отозвать утёкшее.

## Быстрые команды

```bash
pg_ctlcluster 16 main start          # если Postgres не запущен
ruff check . && pytest -q -p no:logging
alembic upgrade head
cd frontend && npx tsc --noEmit && npm run build && npx vite preview --port 4173
python -m app.admin ban <telegram_id>   # блокировка, см. deploy/runbook.md
```
