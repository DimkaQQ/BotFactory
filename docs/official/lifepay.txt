Открытый LIFE POS API

Сервис оповещений
Настройте отправку уведомлений о событиях из LIFE POS Retail: продажи, сотрудники, открытие и закрытие смен. Оповещение передаётся по HTTP-ссылке.
Ограничение функционала приложения
Гибко ограничивайте права доступа сотрудников к функциям кассового приложения. Например, скройте кнопку «Изменить заказ» у всех сотрудников с ролью «Курьер».
Внешний калькулятор скидок
Передавайте из вашей учётной системы информацию о скидках и программах лояльности для расчёта финальной стоимости покупки.
Как работает внешний калькулятор скидок
1
Приложение отправляет состав заказа
Перед приёмом оплаты LIFE POS Retail отправляет на ваш сервер состав заказа для сверки.
2
Сервер отвечает обновлённым составом
Ваш сервер возвращает обновлённый состав продажи, который импортируется обратно в LIFE POS Retail.

Частые вопросы о LIFE POS API
Кому доступен LIFE POS API?
LIFE POS API открыт для всех разработчиков. Документация постоянно обновляется и доступна без регистрации.
Можно ли ограничить права сотрудников через API?
Да. API поддерживает гибкое ограничение прав доступа к функциям кассового приложения — логику можно настроить под нужды вашего бизнеса.
Как получать уведомления о событиях?
Через сервис оповещений: настройте отправку уведомлений о продажах, сотрудниках и сменах — событие передаётся по HTTP-ссылке.

Возможности интеграции облачной кассы LIFE PAY
Облачная касса интегрируется с CRM- и CMS-системами. Открытый API управляет сменами, чеками коррекции, уведомлениями и фискализацией.
Отправка чека на фискализацию
Удалённо фискализируйте чеки без принтера на месте продажи либо агрегируйте платежи из нескольких источников для печати на одном принтере.
Создание нефискального чека
Создавайте нефискальный чек на облачной кассе, передав позиции, сумму, реквизиты точки и кассира, данные принтера.
Создание чека коррекции
Формируйте чек коррекции по требованиям ФНС: инициатор, дата и номер документа, суммы и тип коррекции, информация о налоговой системе.
Удалённое открытие и закрытие смен
Открывайте и закрывайте смены на фискальном регистраторе удалённо, передавая данные кассира и уведомления о статусе смены.

Частые вопросы об облачной кассе
Нужен ли принтер на месте продажи?
Нет. Благодаря удалённой фискализации чеки формируются без принтера на месте продажи, либо платежи из нескольких источников можно печатать на одном принтере.
Можно ли создавать чеки коррекции по API?
Да. Через API можно сформировать чек коррекции, соответствующий требованиям ФНС, передав обязательные и дополнительные поля.
С какими системами интегрируется облачная касса?
Облачная касса интегрируется с CRM- и CMS-системами, а также учётными системами через открытый API.
